# Private fit evidence

Use this template when storing results that will help later parts or agents.
The filled record belongs in the user's designated private project or shared
hardware record, not inside this redistributed skill. No database, server or
particular file tool is required. With no write tools, return the filled text
and say it is not saved.

## Minimum useful record

```text
Date, project and sample ID:
CAD revision and retained source/3MF location:
Mating parts and function: locate / slide / rotate / retain / clamp
Hardware nominal specification; actual measurements and their source:
CAD nominal dimensions, including independent OD/ID/AF/thickness/travel:
Printed measurements and method, if supplied:
Allowance definition: diametral / total AF / per side / axial
Printer, nozzle, material; brand/lot/colour if known:
Layer height, orientation and nearby wall/support geometry:
Slicer profile and hole/contour/first-layer compensation:
Preparation: cooled, debris removed, filed, drilled, or as printed
Assembly check and user's observed result:
Status: accepted for stated setup / failed / untested
Chosen variant and affected production instances:
Limits, remaining checks and proposed next test:
```

Link the exact retained geometry and print project rather than copying private
files into the skill. Distinguish saved profile settings from measured machine
conditions. Fit approval does not prove strength, fatigue, load capacity or
whole-assembly clearance.

## Reusing results without inventing precision

Separate external journals, internal rod holes, bearing housings, nut pockets,
free spacers and clamped collars. A successful collar does not set the clearance
for a running bearing. A reported printed diameter is not the CAD dimension
of a differently printed part.

For a new interface, use a comparable accepted allowance as a starting estimate,
then compare a few labelled coupons with the target hardware. Do not scale the
whole part or silently change already accepted keys, teeth or mating features.
Different results in different setups remain separate records, not a universal
correction. Retest affected interfaces when geometry, orientation, material,
printer/nozzle or meaningful profile settings change.
